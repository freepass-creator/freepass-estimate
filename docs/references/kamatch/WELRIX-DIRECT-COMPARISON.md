# 웰릭스 직접 비교 조회 전달

2026-10-31 UTC · 사용자 후속 지시: https://welrixmobility.netlify.app/ 의 웰릭스 견적은 직접 받아온다.

## 확인 및 로컬 구현

- 공개 POST https://welrixmobility.netlify.app/api/estimate 호출에 성공했다. 응답의 월대여료/보증금/선납금/인수가/총차량가격을 직접 받는다.
- 견적기의 비교 화면 중 '중신용 제휴'를 `/api/welrix-comparison` 서버 경유 실시간 조회로 연결했다. 이 비교 경로는 FreePass Data 서비스 설정을 요구하지 않는다.
- 기존 상품 ID→웰릭스 모델 키 매핑과 옵션 구성축 처리를 재사용한다. 선택 화면 가격을 manualPrice로 보내는 참고 비교 조회이며, 원본 금액을 임의 보정하지 않는다. 응답 모델·수기가격·기간별 결과 수를 검증하고 no-store로 반환한다.
- 비교 결과는 DIRECT_COMPARISON_ONLY다. CANONICAL_ACTIVE 가격 근거를 만들거나 계약/견적 발행 결과로 저장하지 않는다. 기존 정본 Quote 발행 경계는 유지한다.
- 카매치는 아직 39개 관찰값 표시 방식이다. 웰릭스만 실제 API로 연결된 상태를 구분한다.

## 실서버 검증

- 서버 handler 직접 호출에서 아반떼 Modern, 차량가 23,980,000원, 중신용, 연 3만km, 보증금 5%, 선납 0%, 수수료 5%, 용품/탁송 비용 0 조건의 36/48/60개월 응답을 확인했다. 이 조건에서 월 649,000 / 575,000 / 538,000원이었다. 전 조건 공통 고정가격으로 사용하지 않는다.
- 우리 앱의 차량 선택→견적 비교→실시간 조회에서도 실제 API HTTP 200을 확인했다. 화면 기본 조건(중신용·60개월·연 2만km·보증금/선납 0%) 아반떼 모던은 해당 실행에서 월 541,000원으로 반환됐고 화면 표시와 일치했다. 용품/수수료 등 현재 선택 조건을 그대로 전달한다.
- 공식 API 응답은 원본 가격 버전 근거를 제공하지 않으므로 운영 정본 산식 검증 완료를 주장하지 않는다.
- 브라우저 확인, 잘못된 모델/응답 거부, 중신용 요청 검증, 시간초과 시 다른 계산기로 대체하지 않는 테스트 및 빌드를 통과했다.
- 현재 제품 코드는 구현 세션의 로컬 변경이며 이 문서는 진행 공유다. 운영 배포는 아직 하지 않았다.
