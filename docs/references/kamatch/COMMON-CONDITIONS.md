# 최신 사용자 결정 — 정비 제외 · freepass 표준 견적

2026-10-31 후속 직접 지시를 기존 기본값보다 우선한다.

- 새 견적은 전부 정비 제외다. 정비 상품 선택 UI와 웰스 상품명을 없앤다.
- 화면/복사 이미지는 'freepass 표준 견적'으로 표시한다. 계산 제휴사 이름을 상품 브랜드처럼 표시하지 않는다.
- 결과 공통 조건은 약정 주행거리, 보험(대물), 정비 제외, 부가세 포함으로 간단히 표시한다. 기간별 보증금·선납금 비율/금액과 월 대여료는 유지한다.
- 새 QuoteRequest/preview의 정비 값은 '정비 제외'로 고정한다. 오래된 화면 값이 Basic이어도 새 요청을 정비 포함으로 만들지 않는다.
- 외부 계산 어댑터는 provider가 정비 제외로 정의한 내부 코드 '웰스 Self'만 전송한다. 이 코드를 화면 상품명으로 노출하지 않고, 응답 금액을 임의 차감하지 않는다. 실제 API에서 정비 제외 재계산을 확인했다.
- 자체 표준 엔진은 maintMonthly=0, maintRate=0으로 정비 원가를 제외했다. 조건 정책도 '정비 제외'만 허용한다. 엔진 manifest를 1.3.0으로 갱신/검증했다.
- 정비 포함이라고 적힌 기존 견적서 안내/상세 정비상품 표와 외부사 계좌 표기를 정리했다. 이전 정비 포함 공유 견적의 금액을 새 제외 견적으로 위장하지 않고 조건 변경·재계산을 요구한다.
- 실제 브라우저에서 차량 선택→마지막 보증금10%/선납5%/수수료3% 입력→견적→PNG 클립보드 쓰기/되읽기 및 미지원 다운로드를 확인했다. 테스트 당시 아반떼 모던 36/48/60개월은 578,000/523,000/497,000원으로 나왔고 이미지에 같은 금액이 들어갔다. 이는 해당 테스트 조건의 시점 값이지 고정 견적표가 아니다.
- 수집 카매치 관찰값의 과거 조건은 소급해서 '정비 제외'로 바꾸지 않는다. 새로운 정비 제외 조건과의 동등성은 별도 확인한다.

제품 코드 로컬 변경이며 운영 배포는 아직 하지 않았다.
