# 최신 사용자 확정: 제조사 일치 + 웰릭스/카매치 두 실제 견적

앞선 표준 저신용 포함 3개 견적 계획은 폐기. 프리패스 자체 표준은 아직 없음. 우선 웰릭스와 카매치 두 개만 정확하게 받아야 함.

차량 기준: 제조사와 같은 세부모델/파워트레인/세부트림/기본가격/선택옵션가격/외장·내장 추가금. 옵션 배타그룹, 선행조건, 포함 중복, 트림별 선택 가능 조건도 정확히 일치해야 함. 권한은 FreePass Data에 있고 Estimate에 별도 마스터를 만들지 않음.

두 계산기는 같은 차량 구성, 제조사 기준 가격 구성, 기간/보증금/선납금/주행거리/만26세/정비제외/수수료를 입력하고 실제 공급사 응답을 받아야 함. 정확함의 완료 기준은 동일 조건에서 원본 결과와 월료/보증금/선납금/만기 인수가 모두 원 단위 일치.

현재 로컬 정리: 비교에서 자체 표준 제거. 카매치 카드에 수집 관찰값을 현재 견적처럼 표시하지 않고 실제 조회 미연결 표시. 수집값은 참고 접기에 보존. 모바일 비중신용에서 자체 표준 대체계산 제거. 웰릭스 비교 요청은 선택 차량 기준가격을 유지하며 공급사가 이를 무시해 다른 기준가를 응답하면 WELRIX_PRICE_MISMATCH로 중단.

미완료: 제조사 원본 대비 전수 가격/옵션 규칙 검증과 CANONICAL_ACTIVE Data 런타임 연결, 카매치 실제 지원 연동/인증 및 동일조건 응답 검증. 현 선택 자료 가격을 그대로 넘기는 로컬 비교는 제조사 검증 완료/정식 발행 견적이 아님. 관찰 39건 재생으로 카매치 연동 완료 주장 금지.

Work 후속 우선순위: Data의 제조사 근거와 활성 배포/계약 확인 → 옵션 규칙 검증 → 양사 stable ID 매핑 → 실제 조회 어댑터 → 원본 동시 비교. 공급사 가격으로 우리 마스터를 덮어쓰지 말 것.
