## 수집 경로와 보존 경계

공개 홈페이지에 연결된 배포 파일 `https://kamatch.kr/assets/index-CHezQoaB.js`를 인증정보 없이 읽어 계산 흐름을 분석했다. SHA256: `63e50c4abf5b64ae7b80b826c0aa529a31c71cdfae0ab35e000f8e1acc38da22`.

해당 프로그램이 실제 사용하는 읽기 경로만 확인했다: `/api/vehicles`, `/api/fee-rates`, `/api/residual-rates`, `/api/model-fee-rates`, `/api/commission-rates`, `/api/residual-grade-rates`, `/api/gaeso-reg-rates`, `/api/commission-settings`, `/api/supplies-prices`.

일부 표는 비로그인 요청에 401을 반환했다. 인증 제한을 우회하거나 쿠키를 반출하지 않고, 이미 로그인된 사용자 브라우저에서 동일한 읽기 경로를 열어 표시된 JSON을 수집했다. 쓰기·업로드·발주·상담·견적 저장/발송 요청은 실행하지 않았다. 전체 배포 JS, 고객/계정 정보, 로그인 값, 세션 및 쿠키는 저장소에 포함하지 않는다.

## 구현 경계

`apps/new/api/_kamatch/calculate.js`는 현재 다기간 견적 경로의 수식을 독립적으로 표현한다. 기록된 결과 조회/보간/회귀 적합이 아니다. 입력은 검증된 `priceBasis`와 별도 매칭한 `vehiclePolicy`, 계약조건, 공급사 정책이다. 공급사 차량가격을 읽어서 FreePass 기준가격을 덮어쓰지 않는다.

`policy.snapshot.json`은 이번 수집 시점의 공급사 요율 증거다. 갱신·검증된 정책 release 체계나 운영 adapter로 등록한 것은 아니다. 실제 공급사 키와 FreePass Data ACTIVE 상품/옵션/색상 ID의 매핑 및 API/UI 연결은 다음 통합 단계다. 프리패스의 기존 화면을 그대로 재사용하고 공급사 화면·브랜드·자산을 복제하지 않는다.

## 확보한 계산 순서

1. 차량+옵션+유료 색상 가격을 합하고 할인액을 구분한다. 보증금은 설정에 따라 할인 전/후 기준으로 계산한다.
2. 보증금 비율은 상품금리 구간에 매핑한다. 수기 금액의 구간 판정과 비율 선택의 최근접 판정은 원본에서 서로 다르다.
3. 차량의 개소지수로 취득 공급가를 조립한다. 브랜드·출고방식별 상수/출고 할인, 개소지수별 등록비율과 고정 등록비를 적용한다.
4. 등급·기간·주행거리별 잔가에 계산 보정(-5%p)을 적용한다. **계산에 사용하는 잔가와 견적서에 표시하는 잔가는 다를 수 있다.** 표시 강제 하한도 따로 존재한다.
5. 보증금 PMT 반영액, 공급 수수료, 영업 수수료의 공급가 차액을 현재가치/미래가치에 반영한 뒤 월 금리로 PMT를 계산한다.
6. 월 자동차세·보험료·기간별 기타비용·용품 증감·법인수수료를 더하고 선납금을 기간으로 나눠 차감한다. 연령 할증, 설정상 허용된 카드 비용, 주행거리 추가요금도 별도로 반영한다.
7. 현재 다기간 경로는 최종 합계에 100원 단위 올림을 적용한다. 상세 PMT 함수의 중간 반올림값을 다시 더하는 경로와 동일하다고 가정하면 안 된다.

특히 **법인수수료의 기준가격은 현재 다기간 경로에서 할인 전 합계**이고, PMT 공급 수수료는 할인 후 기준이다. 다른 내부 함수의 계산값으로 대체하면 할인 조건에서 오차가 난다. 일반/저신용 비용 필드는 null 보완과 0원 처리도 구별한다. 탁송/기본 용품의 전체 단가를 매번 가산하는 것이 아니라 기본 대비 차액만 반영한다.

## 검증 결과와 한계

- 독립 계산으로 실제 UI 39개 견적의 월료·보증금·선납금·표시 잔가율·잔가금액·취득원가가 **모두 0원 차이**.
- 별도 검증기가 해시가 고정된 원본 프로그램의 순수 계산 부분만 격리 실행했다. 표시 허용 행 중 유효한 가격/개소지수를 가진 **939개 행**, 보증금 5/10/20/30%, 주행 2만/3만km, 선납 0/10%, 일부 실제 옵션 및 연령 조건의 **45,072개 월료 결과가 0원 차이**.
- 이 45,072건은 원본 **프로그램 계산 대조**이며 사이트에 견적을 45,072번 요청한 것이 아니다. 실제 UI 실측 39건과 구별한다.
- 표시 허용 949개 중 9개는 개소지수 미등록, 1개는 가격 0원이다. 원천표에 그대로 남기고 계산 불가로 구분한다. 세부 ID는 source report의 `exclusions`에 있다. 원본의 잘못된 음수/불완전 표시를 정상 견적으로 발행하지 않는다.
- 모든 가능한 복합 옵션 집합·임의 수기 금액·미래 변경 버전까지 운영 검증이 끝났다는 뜻은 아니다. 현재는 원천 확보와 독립 산식 검증 완료 단계이며 **운영 UI/API 연결과 전수 canonical 매칭은 미완료**다.
- 기존 프리패스 표준 엔진 회귀 및 provider 공통 계약 검사 통과. 웰릭스 코드 변경 없음.
