# 고객 표기/조회 방식 — 최신 사용자 확정

마지막 차량·조건 선택 뒤 공급사를 고르는 화면은 폐기한다. 세 견적을 자동으로 함께 조회해 표시한다.

| 고객 표기 | 내부 계산 연결 |
|---|---|
| 신용 무관 | freepass 표준 |
| 소득 확인 | 카매치 |
| 신용 필요 | 웰릭스 |

공급사명은 고객 화면, 비교 제목, 복사 이미지, 고객 공유 스냅샷에 표시하지 않는다. API 공개 응답도 PUBLIC_QUOTE_OPTIONS와 위 세 category ID/금액만 반환한다. 공급사별 원본 필드·URL·예외 메시지는 공개 응답에서 제외한다. 내부 어댑터와 원본 정합성 검증은 유지한다.

모바일 조건에서 공급사 선택 버튼 제거. 모바일 결과와 데스크톱 TermsGrid는 같은 3종 결과 컴포넌트 사용. 복사 이미지는 차량/가격 구성 위에 두고 아래 세 견적을 나란히 압축한다. 계약기간별 금액과 공통 보증금·선납금, 만26세, 정비 제외, 담당자, 참조문자는 유지한다.

공유에는 offers 3개를 당시 금액으로 보존하며 engine은 freepass로 고정한다. 원문 숫자 수수료는 넣지 않고 참조문자만 보존한다. 과거 단일 스냅샷은 누락 견적을 만들어내지 않고 저장된 값으로 읽는다. 일부 조회 실패는 해당 칸을 조건 확인 후 안내로 표시하며 0원이나 타 공급사 금액으로 채우지 않는다.

검증: 공개 API/표기 매핑 테스트, 내부 공급사명이 공개 응답에 포함되지 않는 테스트, 실제 브라우저의 3종×3기간 표시/PNG 클립보드/공유 원금액 보존/공유 페이지 PNG 복사/공급사명 미노출, 스냅샷 회귀, 빌드 통과. 브라우저의 차량·카매치 요율은 명시적 테스트 자료이며 웰릭스는 실제 API를 호출했다.
