# 최신 사용자 확정: 간단 이미지 + 상세 공유 링크

이 지시가 CUSTOMER-CONDITIONS-IMAGE.md의 이미지 구성 설명보다 우선함.

결과 액션은 견적 이미지 복사 / 상세 견적 공유 2개. 별도 손님용 조건 복사 버튼은 통합.
이미지는 차종·트림, 기간별 월 렌트료, 보증금·선납금 비율, 공통 조건만 표시. 수수료 내부 암호 확인번호 유지.
상세 링크에서는 옵션·색상·차량가격·보증금 및 선납금 금액·만기 인수가까지 표시. 공유 당시 계산 스냅샷을 보존하고, 수수료 원문은 링크 데이터에서 제외.
현재 링크는 URL에 공개 스냅샷을 포함하므로 공유에 별도 신규 데이터 저장이 필요하지 않음.
실제 PNG 클립보드 복사 및 새 브라우저 페이지에서 공유 당시 금액/디테일 재현 확인 완료. 로컬 구현이며 미배포.
