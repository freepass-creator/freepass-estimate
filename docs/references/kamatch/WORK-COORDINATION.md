# 최신 실행 작업 — 2026-10-31

사용자 최신 확정은 **제조사와 같은 차량·옵션 가격 + 웰릭스/카매치 실제 견적 2개**입니다. 아래 과거 3종 계획은 폐기 기록입니다. 프리패스 자체 표준 엔진을 제품 견적으로 노출하지 않습니다.

## 이번에 확인한 원본 구조

카매치 공개 앱 /assets/index-CHezQoaB.js에서 계산 함수 By, PMT 기반 N9, Z1 및 gaeso 등록비 조회 J1을 확인했습니다. 서버 견적 POST가 아니라 브라우저 산식 + 인증된 서버 요율/차량 테이블 구조입니다. 계정·차종·기간 요율 없이 과거 화면값만으로 0원 오차 구현을 선언하지 마세요.

현재 클라우드 환경의 /api/vehicles, /api/fee-rates, /api/commission-settings, /api/model-fee-rates, /api/residual-grade-rates, /api/gaeso-reg-rates, /api/residual-rates, /api/supplies-prices는 모두 HTTP 403입니다. 우회 시도 없음.

## 로그인된 Work에서 바로 실행할 작업

1. 이 폴더 capture-browser-reference.js를 현재 로그인된 kamatch.kr 탭에서 실행합니다. 알려진 8개 조회 경로만 GET하며, 견적 저장/계약접수/발송/계정 변경은 하지 않습니다. 쿠키·토큰도 읽거나 반환하지 않습니다.
2. 내려받은 kamatch-private-calculation-reference.json은 로컬 비공개 경로에 보관합니다. 원문 전체를 저장소에 올리지 말고 요율 스키마, 필요한 모델 매핑, 적용일/앱 SHA256 및 검증용 비식별 입력/출력만 기존 references에 기록합니다.
3. 같은 탭에서 36/48/60개월, 보증금·선납금, 수수료 1~5%, 단일/복합 옵션과 유료색상 변경의 실제 결과를 확인합니다. 원본 요율과 계정별 수수료 설정을 고정한 결과가 우선입니다.
4. FreePass Data 소비처 승인 연결은 기존 서버 비밀값 관리 경로로만 설정합니다. FREEPASS_DATA_CONSUMER_BASE_URL 및 FREEPASS_DATA_ESTIMATE_TOKEN이 현재 구현 환경에는 없습니다. 비밀값을 GitHub/대화로 전달하지 마세요.

## 구현 세션이 이번에 실제 수정한 것

- 모바일 새 견적은 CANONICAL_ACTIVE 마스터 조회와 투영을 거쳐야 시작합니다. 연결 실패 시 저장소의 오래된 정적 차량가격으로 대체하지 않습니다. 저장된 공유 스냅샷 읽기는 유지합니다.
- 웰릭스 비교도 동일 서버 마스터에서 옵션 배타·선행조건과 가격을 검증한 뒤 요청합니다. 브라우저 입력 가격 변조, 공급사의 기준가/총가격 변경은 거부합니다.
- 같은 옵션의 트림별 가격/선행조건/배타그룹을 한 묶음으로 합치던 UI 투영 오류를 수정하고 모바일에서 해당 트림의 규칙만 읽게 했습니다.
