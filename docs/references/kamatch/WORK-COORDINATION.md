## 사용자 확정 사항

| 견적 종류 | 계산/제휴 대상 |
| --- | --- |
| 표준 저신용 | 자체 표준 계산 |
| 저신용 제휴 | 카매치 |
| 중신용 제휴 | 웰릭스 |

세 가지 견적을 별도 상품/경로로 구분해야 한다. 신용등급만으로 계산기를 선택하면 표준 저신용과 저신용 제휴를 구분할 수 없으므로 최종 구현은 견적 종류를 명시적으로 보존해야 한다.

화면 브랜드는 회사명 '프리패스모빌리티'가 아닌 작은 소문자 `freepass`다. 연한 색, 보통 굵기로 표시한다. 상품 설명은 '신차 장기렌터카 견적기', 출력물은 '신차 장기렌터카 견적서'를 사용한다. 제조사 로고는 배경 없이 심볼만 표시한다.

## 받은 자료와 현재 판단

이 브랜치의 README.md, parity-status.json을 읽었다.
아반떼 2개 모델, 13개 구성, 기간별 39개 관찰 결과를 확인했다.
원 단위 완전 동일 요구와 NOT_VERIFIED 상태를 인지했다.
관찰 데이터 재생을 운영 계산기로 등록하거나 근사식으로 동일 구현을 주장하지 않는다.
운영 제휴 연동 완료로 표시하지 않는다.

## Work 세션에 요청

1. 이 문서를 읽은 뒤 아래 'Work 응답'에 확인 내용, 진행 상황, 다음 요청을 기록하고 이 공유 브랜치에 커밋해 주세요.
2. 저신용 제휴(카매치)를 위한 정식 계산 연동/API 제공 여부, 이용 가능한 공식 문서와 운영자 문의 필요 사항을 정리해 주세요. 확인하지 못한 사항은 미확인으로 남겨 주세요.
3. FreePass Data의 기준 차량가격을 카매치 산식 입력으로 전달할 수 있는지, 실제 계산에 반영되는지를 확인할 수 있는 근거가 필요합니다. 화면의 차량가격 수기 변경만으로 API 지원을 확정하지 않습니다.
4. 원본 산식/요율표, 기간별 잔가, 옵션/용품 비용 처리, 수수료, 반올림 순서, 버전/적용일 등 완전 동일 구현의 미확보 항목을 기존 parity-status.json에 계속 기록해 주세요.
5. 기존 자료를 유지하고 관찰 사실과 추정/미확인을 분리해 주세요. 로그인 정보, 세션 쿠키, 토큰, 고객 개인정보는 올리지 않습니다. 발주/저장/견적 발송은 별도 지시 없이 실행하지 않습니다.

## 구현 세션 현재 상태

- 저장소 main d483fd46 기반 로컬 변경을 보유하고 있습니다. 제품 변경은 아직 GitHub에 커밋/병합/배포하지 않았습니다.
- 작은 소문자 freepass 워드마크, 여섯 제조사 심볼, 견적서 로고, 초기화 오류 및 로컬 API 경로를 수정했습니다.
- 중신용 요청을 웰릭스 어댑터로 보내는 라우팅을 구현하고 계약/실행/오류 시 fallback 금지 테스트와 빌드를 통과했습니다. 이 결과는 테스트 환경 검증이며 실서버 금액 검증을 뜻하지 않습니다.
- 그 뒤 사용자가 견적 3종을 확정했습니다. 견적 종류를 별도로 선택/보존하는 최종 3종 구조와 카매치 운영 어댑터는 아직 미구현입니다.
- 실제 견적 검증에는 FreePass Data 서비스 연결과 CANONICAL_ACTIVE 마스터 및 각 provider의 검증된 산식 근거가 필요합니다.
- 이 문서는 자료 공유용이며 main 병합이나 운영 배포를 요청하는 문서가 아닙니다.
