# 카매치 대여료·옵션 산출 대조 자료

관찰일: 2026-10-31 (Asia/Seoul) · 출처: https://kamatch.kr/

## 범위와 사용 목적

사용자의 최종 지시에 따라 캡처 없이 로그인 후 보이는 차량·트림·조건·결과를 데이터로 정리했다. 상담·출고 요청·견적 저장·발송은 실행하지 않았다. 로그인 정보, 쿠키, 토큰, 고객·담당자 정보, 연락처와 계좌번호는 포함하지 않는다.

이 자료는 **원본 산식이 아닌 실제 화면 입출력 관찰 자료**다. 아반떼 2개 모델에서 13개 구성 × 3개 기간 = 39개 결과를 수집했다. 전 차종 수집 또는 운영 연동 완료를 뜻하지 않는다. 다른 신용·보험·주행거리·출고방식에 일반화하면 안 된다.

- `observations.json`: 전체 입력 조건과 기간별 실제 출력. 가격의 원 단위 차이도 유지한다.
- `mapping-review.json`: 우리 저장소 스냅샷과 비교한 매칭 후보 및 최신화 대상. 운영 master 확정 ID가 아니다.
- `replay-quote.mjs`: 수집된 **정확히 동일한 입력**만 재현하는 개발용 조회 함수. 추정식·보간·기본값 대입을 하지 않는다. 운영 provider로 등록하지 않았다.
- `verify.mjs`: 기록 무결성, 옵션 증감, 미수집 조건 거부 검증.

## 우리 데이터와 매칭

공장옵션 추가는 총차량가격·취득원가·보증금·잔존가치에도 반영됐다. 반면 위 용품/썬팅 변경에서는 표시 차량가격·보증금·잔가가 유지되고 월료만 달라졌다. 공장옵션과 출고용품을 같은 산식으로 취급하면 안 된다.

선루프와 스마트센스의 단독 월료 증감을 더한 값은 복합 적용값과 100원 차이가 난다. **옵션마다 반올림한 가산료를 단순 합산하는 식은 관찰값을 재현하지 못한다.** 공통 원가를 조립한 후 최종 단계에서 처리하는 구조가 후보이나 정확한 반올림·절상·절사 순서는 미확정이다.

관찰한 잔가율은 36개월 74%, 48개월 64%, 60개월 54%다. 이 모델/조건에서의 결과이며 전 차종 공통표로 확정하지 않는다. 보증금과 선납금의 비율 기준, 금리·보험료·세금·수수료·잔가표·최종 반올림 규칙의 원본은 확보하지 않았다. 선납금 차감이 대략 `선납금 / 기간`과 비슷해도 이를 확정식으로 구현하지 않는다.

## 입력·버튼 동작

차량 선택 순서: 브랜드 → 모델 → 라인업 → 트림 → 외장/내장 → 상세 옵션. 트림 메뉴 가격과 실제 상세 가격을 별도 보존해야 한다. 상위 선택을 바꾸면 하위 선택과 보증금이 재설정되는 경우가 관찰됐고 선납금은 유지됐다. 다른 모델 견적을 이어 계산할 때 매번 전체 조건을 읽어야 한다.

36/48/60개월 체크는 하나의 결과표에 기간별 열을 추가한다. 조건이나 옵션을 변경하면 별도 계산 버튼 없이 결과가 갱신된다. 변경 직후 차량 표시가격은 바뀌어도 취득원가/월료가 잠시 이전 값일 수 있으므로 새 결과가 반영됐는지 확인해야 한다. 차량명·차량가격 직접 입력과 할인금액/메모 입력이 있다.

공장옵션은 가격을 표시하는 토글 버튼이다. 신형 프리미엄에서 와이드 선루프 900,000원, 현대 스마트센스Ⅱ 400,000원, 라이팅 플러스 패키지 150,000원 메뉴를 확인했다. 마지막 항목은 산출 실험하지 않았다. `+ 썬팅(썬루프) 추가`는 일반/파노라마 두 행을 동시에 추가했다. 각 행 ×로 제거 가능하다. 블랙박스 ×는 제외 후 ↺ 복원 버튼으로 바뀐다.

보증금은 5/10/15/20/25/30%, 선납금은 0/5/10/15/20/25/30% 메뉴를 확인했다. 각각 수기 입력 전환도 있다. 계약구분·만기처리·연간거리·보험연령은 선택 항목이나 전체 선택지 및 조건별 계산은 이번 범위에서 미수집이다.

`이미지 및 견적 저장`, `차량출고요청`, 상담/발송 기능은 실행하지 않았다. `재고현황`의 즉시출고가는 월 대여료가 아니다. 조회 시 총 재고 30,549대, 그룹 목록 15,373건/308페이지를 표시했으며 이것을 전부 견적 산출 가능한 모델 수로 해석하면 안 된다.

## 같은 산출방식을 구현하기 위한 다음 검증

1. 카매치 최신 모델/라인업/트림/공장옵션 전수를 수집하고 FreePass Data의 실제 ACTIVE release와 대조한다. 같은 트림명·다른 세대는 별도 후보로 다룬다.
2. 차종/기간별 잔가표, 금리, 보험/세금, 보증금 할인, 선납금 처리, 용품 금융비용, 수수료, 반올림 규칙을 원본 산식/공식 연동 또는 충분한 교차 실험으로 확보한다.
3. 카매치의 차량가격 수기 변경이 결과에 적용되는 것은 확인했다. 공식 provider가 FreePass canonical 가격 override를 지원하는지는 별도 검증이 필요하다. 웹 UI의 입력 가능성을 API 계약으로 간주하지 않는다.
4. 확정된 계산 provider를 기존 QuoteRequest/QuoteResult 경계에 추가하고, 수집된 39개 결과 및 미수집 차종/복합조건으로 회귀 검증한다. 현 자료만으로 운영 계산기를 대체하지 않는다.

검증 실행: `node docs/references/kamatch/verify.mjs`.
