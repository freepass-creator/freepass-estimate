# 두 공급사 견적 작업 검증 — 2026-10-31

## 사용자 목표

제조사 가격/구성과 일치하는 모델 → 세부모델 → 파워트레인 → 세부트림을 선택하고, 정확한 배타·선행조건을 적용한 옵션/색상을 동일한 가격으로 웰릭스와 카매치에 전달한다. 프리패스 자체 표준 견적은 제외한다.

## 이번 구현

- 모바일 새 견적은 기존 FreePass Data CANONICAL_ACTIVE 소비 계약을 읽고 기존 UI 투영기로 구성한다. 활성 Data가 없으면 정적 구형 목록으로 대체하지 않는다. 이미 공유한 스냅샷 읽기는 보존한다.
- 동일 옵션의 트림별 가격/선행조건/제외조건/배타그룹이 공통 variant 규칙에 합쳐지는 오류를 수정했다. 모바일과 데스크톱 getter는 선택 트림의 규칙을 우선한다.
- 웰릭스 비교 handler도 서버 master에서 가격과 선택 조합을 확인한다. 화면에서 가격을 바꿔 보내도 master가 덮어쓴다. 공급사가 기본가나 총차량가격을 무시하면 계산을 거부한다.
- 이미지/공유에는 서버가 반환한 기본가·옵션·색상·할인 구성과 합계를 사용한다.
- 기본 provider 설정과 비교 목록에서 자체 표준 fallback 제거. 데스크톱 자체 표준 가격표 진입점 제거. 카매치 관찰값은 참고 접기에만 남기고 현재 견적 카드에는 미연결 표시한다.
- 카매치 공개 앱의 계산 함수와 8개 요율/차량 조회 경로를 확인했다. 실행 파일과 앱 digest는 live-integration-discovery-20261031.json에 기록했다.
- tools/kamatch/capture-browser-reference.js는 로그인된 같은 사이트 탭에서 조회만 하고 비공개 JSON 파일을 내려받는다. 쿠키/토큰 접근, 견적 저장, 발주, 발송 기능은 없다. 기존 Work 공유 폴더에도 같은 실행 파일과 정확한 실행 절차를 전달했다.

## 검증

- canonical master UI 테스트 자료로 선택 → 유료 옵션 → 조건 → PNG 클립보드 → 별도 페이지 공유 스냅샷까지 브라우저 확인.
- 실제 master 연결 설정이 없는 브라우저에서 구형 목록 fallback 없이 중단되는지 확인.
- 웰릭스 실제 API에 테스트 master를 주입한 36/48/60개월 호출 성공. 이는 실제 운영 master 연결이나 제조사 전수 일치 증명이 아니다.
- 브라우저 가격 변조 대체, 공급사 가격 무시 거부, master 연결 실패, 옵션 선행조건/명시 제외/배타그룹/다른 트림 옵션 거부 검증.
- 트림별 옵션 투영, 옵션 선택 규칙, 수수료 코드 총 12개 테스트 통과.
- provider contract, share snapshot/재공유/개인정보 제한, master 경계, price assembly, build 및 diff 검사 통과.

## 실행으로 확인된 외부 접근 한계

카매치의 알려진 차량/요율 조회 8개 경로는 현재 이 환경에서 모두 HTTP 403이다. 로그인된 브라우저 도구는 연결돼 있지 않다. 토큰·쿠키를 추출하거나 인증을 우회하지 않았다.

현재 환경에는 FREEPASS_DATA_CONSUMER_BASE_URL / FREEPASS_DATA_ESTIMATE_TOKEN 설정과 승인된 Google Application Credentials가 없다. 따라서 운영 제조사 master를 읽거나 가격을 최신화/활성화하지 않았다. Data 저장소/운영 데이터에 별도 쓰기를 만들지 않았다.

**제조사 전수 대조와 카매치 실제 요율에 의한 0원 오차 검증은 완료되지 않았다. 현재 제품을 양사 정확 견적 완성/운영 배포 완료라고 표현하면 안 된다.**
