# 사용자 최종 범위 — 견적 확인 + 수수료율 조절

2026-10-31 후속 직접 지시를 우선한다.

- 목적: 회원사에 배포할 신차 견적기. 사용자는 차량·조건을 선택해 견적 금액을 확인하고 수수료율을 조절한다.
- 실적 포털, 회원사 계약/출고 관리, 별도 계정 체계, 회원사별 실적 집계를 이 작업에 추가하지 않는다. 구현 세션이 앞서 만들었던 실적 포털은 견적기에서 제거하고 별도 로컬 초안으로만 보존했다.
- 기존 견적 3종(표준 저신용 / 저신용 제휴 카매치 / 중신용 제휴 웰릭스)은 유지한다.
- 현대·기아·제네시스 우선. 르노·KG모빌리티·쉐보레도 카매치 실제 취급이 확인된 범위에 맞춘다.
- 수수료율 입력은 시작 화면, 조건/결과와 비교 화면에서 같은 상태를 사용한다. 비교 화면에서 변경하면 기존 금액을 비우고 재계산한다. 저장된 공유 견적의 원본 금액은 임의 변경하지 않는다.
- 화면의 손님/담당자 이름·연락처 입력은 간단 견적 확인 흐름에서 제거한다. 계정/PIN이나 계약 확정 기준 질문으로 견적 확인을 막지 않는다.
- 실제 카매치 연동/차종 최신화의 미확인 사항은 기존 문서대로 구분한다. 수집 관찰값을 완전 동일 운영 계산기라고 주장하지 않는다.
