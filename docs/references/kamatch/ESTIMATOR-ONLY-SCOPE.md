# 사용자 최종 범위 — 차 선택 후 조건 입력 · 견적 이미지 복사

2026-10-31 최신 직접 지시를 우선한다.

- 목적: 회원사에 배포할 신차 견적기. 별도 실적 포털/계약·출고 관리/새 계정 체계는 추가하지 않는다.
- 흐름: 제조사 → 모델 → 파워트레인/필요 구성 → 트림 → 색상 → 옵션 → 용품·서비스 → 마지막 조건(기간·주행거리·보증금·선납금·수수료율) → 견적 결과 → 견적 이미지 복사.
- 보증금·선납금·수수료율은 시작 화면에서 제거하고 마지막 조건 화면에 모았다. 이전 이동 시 선택과 입력값을 유지한다.
- 결과 화면에서 바로 PNG 이미지를 클립보드에 복사한다. 미지원/거부 기기에서는 PNG 저장으로 대체하고 실제 처리 결과를 안내한다. 계산 중/실패/조건 변경 시 이전 금액을 복사하지 않는다.
- 기간별 견적 이미지에는 선택한 보증금·선납금 비율 및 실제 금액, 월 대여료, 인수가, 차량·선택조건을 포함한다. 수수료 조절 입력과 개인 이름·연락처 입력은 최종 견적 이미지에 넣지 않는다.
- 웰릭스 중신용의 화면 조회는 실제 웰릭스 API 결과를 표시하는 전용 display runtime을 사용한다. canonical Quote 저장/계약 발행 근거로 승격하지 않는다. 공개 API가 받는 기간은 36/48/60개월이며, 일부 차종은 60개월 미지원이므로 지원하지 않는 조합의 오류를 다른 산식으로 덮지 않는다.
- 기존 견적 3종(표준 저신용 / 저신용 제휴 카매치 / 중신용 제휴 웰릭스) 구분을 유지한다. 카매치는 아직 수집 관찰값 비교 상태다. 표준 계산의 Data 연결은 미완료다.
- 현대·기아·제네시스 우선, 르노·KG모빌리티·쉐보레는 카매치 실제 취급 확인 범위에 맞춘다.
- 브라우저에서 아반떼 모던/보증금10%/선납5%/수수료3% 실제 웰릭스 결과를 조회하고 36/48/60개월 583,000/528,000/502,000원 표시와 동일한 PNG의 클립보드 쓰기·되읽기(187,689 bytes)를 확인했다. 복사 미지원 시 다운로드, 뒤로 이동의 입력값 유지도 확인했다. 이 숫자는 해당 테스트의 나머지 선택조건 기준이며 고정 견적표가 아니다.
- 제품 코드는 로컬 변경이며 운영 배포는 아직 하지 않았다.
