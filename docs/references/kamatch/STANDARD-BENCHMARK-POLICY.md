# 최신 사용자 지시 — 제조사·제휴 정합성과 자체 표준 추정

이 지시로 이전 '자체 표준 제외/두 공급사만' 계획을 대체한다. 웰릭스·카매치를 원본과 정확하게 대조하고, 그 결과에서 잔존율/수익률을 추정해 freepass 표준 견적을 만든다.

## 구현

- quote-benchmark는 Data CANONICAL_ACTIVE master를 한 번 고정하고 같은 차량·옵션·색상·계약 조건으로 두 어댑터를 호출한다. 기준가격과 공급사 응답은 일치해야 한다.
- 웰릭스는 공개 화면의 직접입력가 전송 방식을 확인해 old=true와 manualPrice를 함께 보내도록 수정했다. 이 필드는 공급사 가격선택 기능이다. FreePass 상품은 신차 그대로다. 같은 가격에서 기존 방식과 36/48/60개월 금액이 일치하고 +100만원 변경이 계산 사슬 전체에 반영됨을 실제 API로 확인했다.
- 아반떼에 이어 쏘나타/카니발/G80/테슬라 모델Y까지 가격선택 방식의 같은-가격 동등성 및 가격변경 반영을 확인했다. 제조사 master 확인 또는 해당 전 차종 전수 견적 대조를 뜻하지 않는다.
- 각 견적의 인수가/총차량가로 잔존율을 구하고, 보증금 반환·선납금·회사1P+영업P 수수료·알려진 용품비를 포함한 현금흐름에서 내재수익률을 역산한다. 실제 금융사의 보험/세금/할인 원가가 미분리된 경우 금융 IRR로 확정하지 않는다.
- 자체 표준은 현재 같은 구성의 두 공급사 잔존율과 월 내재수익률에 동일 가중치를 적용한 추정 정책이다. 월료는 100원 올림. CURRENT_CANONICAL_CONFIGURATION_ONLY로 범위를 제한하며, 고객 이미지/공유 링크에도 freepass 표준 추정 표시를 보존한다.
- 제조사 근거와 Data master의 모델/파워트레인/트림/가격/옵션·색상/배타·선행·포함 관계 및 제휴 제공 견적의 전체 입력·5개 금액을 0원 허용오차로 대조하는 읽기 전용 감사기를 추가했다. 미확인 가격을 보간하거나 master에 쓰지 않는다.

## 실제 원문 확인과 수정

Data의 기존 기아 공식 가격 파서를 쏘렌토 공식 페이지에 실행해 파워트레인 혼합/반응형 메뉴 중복/가격만 있는 옵션/세제혜택 기준 오류를 수정했다. 원래 Data 저장소의 PR https://github.com/freepass-creator/freepass-data/pull/834 (DRAFT), source commit 411414f, handoff commit 9d54864. 해당 원문은 24개 오분류·중복 후보에서 3개 파워트레인 × 5개 트림=15개로 정리됐다. 운영 적재/정본 승격/소비처 배포는 실행하지 않았다.

## 실측 민감도 실험

calibrate-welrix-curves.mjs는 제휴 원본에 별도 저장 없는 읽기 요청만 보내며, 제조사 가격 근거로 사용하지 않는 실험이다. 아반떼 1개 모델에서 기간3 × 영업P3 × 가격5 = 45개 금액을 관측(총16 API 요청). 27개로 가격 기울기/고정 월비용/잔가를 추정하고 별도18개 가격조건을 대조했다. 추정곡선의 최대 외부 대조 오차는 약1,417원으로, 이 근사식을 원본 공급사 견적을 대체하는 데 사용하지 않는다. 원본 직접조회 어댑터의 0원 정합성 요구는 유지한다. 실제 대출원가를 모르는 상태에서 결과를 금융사 확정 IRR이라고 부르지 않는다.

## 검증 상태

- 원본 카매치 산술 12,032개 비교, 수수료/보증금/선납/기간 및 유료 옵션·색상 어댑터 대조, 회사고정/참조문자 왕복 테스트 유지.
- 현금흐름 역산/가격 민감도 분리/같은 master 고정/두 공급사 누락 및 가격 차이 거부/제조사·제공견적 1원 차이 탐지 테스트 통과.
- 브라우저에서 세 견적의 실제 금액 표시, 잔존율·내재수익률 표시, 표준 선택 → 추정 표시 → PNG 복사 → 공유 페이지의 추정 표시 유지 확인. 브라우저 테스트의 차량/카매치 요율은 합성 테스트 자료, 웰릭스는 실제 API다.
- 실제 운영 Data 연결, 현대·제네시스 포함 전 차종 공식 자료 전수 대조, 카매치 로그인 계정의 원본 요율·화면 대조는 여전히 실자료 연결 단계다. 테스트 자료로 이를 완료 처리하지 않는다.
