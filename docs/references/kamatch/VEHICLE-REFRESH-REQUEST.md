## 확인 사실

## 즉시 수정한 비교 동작

- 사용자 직접 조회 지시 범위의 웰릭스 비교 요청은 manualPrice=0으로 보내 웰릭스 현재 기본가격으로 계산한다. 오래된 선택 화면의 기본가격을 강제로 주입하지 않는다.
- 우리 선택자료 기준가와 웰릭스 현재 기준가를 함께 표시하고 차이가 있으면 최신화 필요를 알린다. 옵션/색상은 아직 우리 선택자료 기준이며 최신 구성 검증이 필요하다고 표시한다.
- 쏘나타 실제 API 확인: 우리 옛 기본가 29,330,000원을 가진 선택 요청에서도 웰릭스가 현재 29,430,000원으로 계산했다. 중신용 60개월/연2만km/보증금0/선납0/용품비0/수수료5% 테스트 결과 월651,000원. 테스트 시점 조건값이며 고정 표로 사용하지 않는다.
- 이 변경은 직접 비교 조회 전용이며 중앙 vehicle master를 웰릭스 가격으로 덮어쓴 것이 아니다. 계약 발행용 canonical Quote 가격 근거를 위조하지 않는다.
