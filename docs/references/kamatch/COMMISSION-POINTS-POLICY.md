# 최신 사용자 확정 수수료 정책

총 조정 가능 최대 6P = 회사 고정 1P + 영업사원 0.0~5.0P. 영업 입력 단위는 0.1P, 기본 영업 입력은 0.0P(계산 합계 1.0P). 과거 총수수료 저장키와 분리한다.

UI 입력과 이미지 참조코드는 영업 P를 뜻한다. 계산기에 전달하는 수수료는 회사 1P를 합한 총 P다. 예: 영업 2.5P → 공급사 계산 3.5P. 카매치 원본의 3/4P 공급 기준을 임의로 6P로 바꾸거나 고정 1P를 중복 가산하지 않는다.

서버 전용 문자표 A=0, B=1, C=2, D=3, E=4, F=5, G=6, H=7, I=8, J=9. 앞글자는 정수, 뒷글자는 소수 첫째 자리. AA=0.0P, AB=0.1P, BA=1.0P, CF=2.5P, FA=5.0P. 새 견적 이미지는 오른쪽 아래 작은 '참조 CF' 형태로 표시한다. 과거 긴 Q1 암호문은 기존 CLI 복원 호환만 유지한다.

고객 공유 링크에는 숫자 수수료를 넣지 않고 참조문자만 보존한다. 공유받은 견적을 이미지로 다시 복사해도 같은 참조문자가 남는다. 51개 P 입력 왕복 복원 및 회사 고정 합산, API/비교/미리보기, 실제 PNG와 공유 링크 보존을 검증했다. 브라우저 검증의 차량/카매치 요율은 명시적 테스트 자료다.
