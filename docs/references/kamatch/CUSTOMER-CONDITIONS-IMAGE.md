# 손님용 조건 이미지 및 수수료 내부 확인

사용자 확정: 견적 확인과 수수료 조정만 제공. 계약 관리 시스템은 만들지 않음. 손님에게 전달하고 계약 접수에 활용할 별도 조건 이미지 복사 버튼 추가.

- 차량, 옵션, 보증금, 선납금, 기간별 월 납입금, 공통 조건 표시.
- 표기는 freepass 표준 견적, 정비 제외. 공급사 이름 비노출.
- 수수료 숫자는 고객 이미지에 표시하지 않고 접수 확인번호에 암호화.
- 1~5% 왕복 복원 검증 완료. 동일 수수료라도 무작위 번호 생성. 공개 고정 대응표 없음.
- 서버 전용 FREEPASS_CUSTOMER_REFERENCE_KEY 필요. 브라우저 환경변수나 저장소에 키를 넣지 말 것. 배포 전 관리형 서버 비밀값 설정 필요.
- 복원은 내부 운영 CLI만 제공. 공개 복호화 API 없음.
- 실제 PNG 클립보드 복사, 다운로드 대체 동작, 선택 3% 복원, 브라우저 빌드에 키 미포함 확인.

현재 로컬 구현/검증 완료 상태이며 제품 배포는 아직 하지 않았음.
